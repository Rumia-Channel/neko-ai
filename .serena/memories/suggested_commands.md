# 推奨コマンド

## 開発コマンド
```bash
# アプリケーション実行
cargo run

# ビルド
cargo build
cargo build --release

# チェックのみ（高速）
cargo check

# 依存関係の追加
cargo add <crate-name>
```

## コード品質
```bash
# フォーマット
cargo fmt

# リンタ
cargo clippy

# テスト
cargo test
```

## デバッグ
```bash
# 詳細なビルド出力
cargo build --verbose

# クリーン
cargo clean
```
